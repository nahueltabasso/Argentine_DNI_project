== *Introduction*

This is a research project focused of the identification, extraction and verification of the data contained in Argentine identity documents. This project was developed only for academics and learning purposes in the field of image processing and text recognition. The main objective of the project is to create an automated system that could recognize and validate the contained information on the Argentine ID-Cards accurately and efficiently. All the images used in this project are for educational purposes only and and I have the consent of members of my family and friends to use their ID-Cards for it.

This project has two parts: 

* Research ─► Focused on the research and development of algorithms for automatic identification, extraction, and verification of data from Argentine ID-Cards.
* Application ─► Focused on the development of APIs Rest for interacting with the automated system. For more information refer to this link https://github.com/nahueltabasso/Argentine_DNI_project/blob/main/app/README.adoc[App Readme].

== Data & ethics

WARNING: The dataset is not public. Real samples were used with the consent of their owners
and only synthetic examples are published. This project is for academic purposes only.

NOTE: The data of the files that you could found inside of `research` directory was taken from *synthetic* ID-Cards. So it does not represent real personal information.

== Pipeline overview
....
image ─► [00] DNI detection (YOLO26s-OBB) ─► crop + perspective correction
      ─► [01] elements detection (YOLO26s) ─► readers: PDF417 · MRZ · address
      ─► data validation ─► REST API (FastAPI)
....

== *Features* 

* Automatic identification of Argentine ID-Cards.
* Automatic identification of the elements of Argentine ID-Cards.
* Extraction of relevant data such as document number, pdf417 or MRZ codes.
* Verification of the validity of the extracted data.
* Image processing and text recognition using advanced techniques.
* API Rest for interacting with the automated system.

== *Getting Started*

[source, bash]
----
git clone https://github.com/nahueltabasso/Argentine_DNI_project.git
cd Argentine_DNI_project
pip install -r requirements_research.txt
----

=== *Using Poetry as Package Manager*
[source, bash]
----
# Create the virtual environment and install dependencies
poetry config virtualenvs.in-project true
poetry install
----

=== *Using Docker*
[source, bash]
----
docker compose build research
docker compose up -d research
----
