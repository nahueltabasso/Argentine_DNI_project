== *Getting Started*

To get started with this project, follow these steps:

[source, bash]
----
git clone https://github.com/nahueltabasso/Argentine_DNI_project.git
cd Argentine_DNI_project
----

The service runs in a Docker container.

[cols="2,2,4", options="header"]
|===
| Variable | Default | Description

| `YOLO_DNI_DETECTOR` | *required* | Path to the DNI detector weights (YOLO26s-OBB)
| `YOLO_ID_ELEMENTS_DETECTOR` | *required* | Path to the elements detector weights (YOLO26s)
| `ADDRESS_STRATEGY` | `vlm` | `paddleocr` or `vlm` (Gemini)
| `GOOGLE_API_KEY` | — | Required when `ADDRESS_STRATEGY=vlm`
| `VLM_MODEL` | `gemini-3.6-flash` | Gemini model used for the address
| `PROMPT` | `""` | Prompt sent to the VLM
| `DEVICE` | `cpu` | `cpu`, `cuda` or `mps`
| `DOC_CONF` / `ELEM_CONF` | `0.6` | Confidence thresholds
| `LOG_LEVEL` | `INFO` | Logging level
| `API_PREFIX` | `/api/v1` | API route prefix
|===

WARNING: If `ADDRESS_STRATEGY` is not set, it defaults to `vlm` and the app
will fail to start without `GOOGLE_API_KEY`.

After that, you can built and run the Docker container using the following commands:

[source, bash]
----
# First build the Docker image for the API service
docker compose build api
# Then start the API service in detached mode
docker compose up -d api
----

== *API Reference*

Base URL: `http://localhost:8001/api/v1` +
Interactive docs (Swagger UI): http://localhost:8001/docs

[cols="1,3,2,4", options="header"]
|===
| Method | Endpoint | Form fields | Description

| GET  | `/health` | — | Health check
| POST | `/document/detect` | `file` | Detects the DNI and returns side, OBB points and confidence
| POST | `/document/extract?side=front\|back` | `file` | Extracts the data from one side of the DNI
| POST | `/document/extract-full` | `front`, `back` | Extracts both sides and cross-validates the data
|===

=== Example

[source,bash]
----
curl -X POST "http://localhost:8001/api/v1/document/extract-full" \
  -F "front=@dni_front.jpg" \
  -F "back=@dni_back.jpg"
----

=== *Error responses*

[cols="2,1,3", options="header"]
|===
| `error_code` | HTTP | When

| `INVALID_IMAGE_ERROR` | 400 | The file is not a valid image
| `DOCUMENT_NOT_FOUND_ERROR` | 422 | No DNI detected in the image
| `MULTIPLE_DOCUMENTS_ERROR` | 422 | More than one DNI detected
| `SAME_SIDE_ERROR` | 422 | `front` and `back` are the same side
| `NOT_MATCH_SIDE_ERROR` | 422 | The detected side does not match the requested one
| `UNKNOWN_CLASS_ERROR` | 500 | The model returned an unknown class
|===
