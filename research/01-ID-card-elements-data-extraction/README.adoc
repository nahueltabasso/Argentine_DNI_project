== *Executive Summary*

This work builds an *end-to-end pipeline* to detect and extract data form the elements of the Argentine ID Card (DNI) using a *YOLOv26* model and OCR techniques for character reading.


== *Fine-tuning the YOLOv26 model*

=== *Introduction*

To do this work, thanks to the DNI detector trained in the previous stage of the project, Argentine documents were extracted and cropped with prior perspective correction to remove backgrounds and rotations.

After, with a *pre-labeling* pipeline, the elements of the DNI were labeled and a dataset was created. The dataset was split into training, validation and test sets.

=== *Problem Statement*

Detect and localize the elements of the Argentine ID card in images.

=== *Success Criteria*

* Detect the elements of the Argentine ID Card (DNI) in images.
* Achieve a mAP@50 >= 85 and mAP@95 >= 80

=== *Scope*

* *In scope:* card elements detection (multiple classes).
* *Out of scope:* OCR, face detection, MRZ reading, etc.

== *Libraries & Tools*

* Download the weights from https://platform.ultralytics.com/ultralytics/yolo26/yolo26s[YOLO26S].
* Fixed `seed=42` in `TRAIN_CFG`.
* Weights stored at `weights/yolo/yolo26s.pt`

=== *Dataset*

Were used samples from the **dataset** of the previous stage of the project as input data for the **pre-labeling** pipeline. The annotations of the elements of the DNI were generated and a new dataset for this stage was created with the follwing classes:

* `picture`
* `shield`
* `doc_number`
* `tramite_number`
* `gender`
* `pdf_417`
* `country`
* `mrz`
* `address`

Afterwards, the annotations of the different classes were corrected using *CVAT*. Then, the final **dataset** was split into `train`, `val` and `test` sets, leaving for the **test set** real DNI images (family, friends, public images from the internet).

=== Limitations & assumptions

* The test set is *small (32)*.
* The dataset is *not public* (except the synthetic examples).

== *Process Overview*

The dataset construction and model training were split into a sequential pipeline of four notebooks. Each notebook produces the input for the next one, following the
naming convention `NN_<step>_vX.Y.Z.ipynb`.

[cols="1,3,3,3", options="header"]
|===
| # | Notebook | Goal | Output
| 00
| `00_extract_DNI_from_image`
| Extract the elements of the Argentine ID Card from images with our trained YOLOv26 OBB model.
| Extracted Argentine ID cards.

| 01
| `01_annotate_elements_of_DNI`
| Auto-label the elements of the Argentine ID Card usign the `coords_data.json` file generated in the previous stage.
| Pre-labeled real samples in YOLO format.

| 02
| `02_review_correct_labels`
| Quality control: inspect the pre-labeled dataset in **FiftyOne** and fix the
wrong boxes in **CVAT**.
| Curated and corrected ground-truth dataset.

| 03
| `03_train_and_metrics`**
| Fine-tune the **YOLOv26 Small** model with the curated dataset and evaluate the performance on the test set.
| Fine-tuned weights (`yolo26s_ID_elements_det.pt`) and evaluation report.
|===

=== *Evaluation protocol*

Metrics are computed *only on the test view* to avoid counting train/val ground
truths as false negatives.

[cols="2,1,3", options="header"]
|===
| Parameter | Value | Role

| `conf` | 0.5 | Min confidence to keep a detection (inference)
| `iou` (NMS) | 0.5 | Suppress overlapping duplicate boxes (inference)
| `iou` (eval) | 0.5 | Min overlap to count a prediction as TP (evaluation)
|===

[NOTE]
====
Elements with larger physical area or high-contrast patterns (`picture`, `pdf_417`, `mrz`, `address`) achieved perfect F1-scores (1.00). Smaller text elements such as `gender` (F1=0.87) and `tramite_number` (F1=0.95) represent the main bottleneck due to lower recall on smaller bounding box areas.

=== *Conclusions*

* Residuals errors concentrate on `gender` and `tramite_number` classes, which are smaller text elements.
* The model is able to detect and localize the elements of the Argentine ID card in images.
* Small dataset and limited test set size with an advantage that is composed by real images of Argentine ID cards.
